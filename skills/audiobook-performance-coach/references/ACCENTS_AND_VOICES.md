## 1. Separate accent from delivery

Accent concerns pronunciation patterns. Dialect can include grammar and vocabulary.
Do not rewrite dialect into prose. Keep all source words intact.
Character identity persists across scenes. Delivery responds to the present situation.

| Aspect | Baseline | Situation change |
|---|---|---|
| Accent | chosen pronunciation patterns | retain unless switching is supported |
| Register | habitual degree of formality | listener, setting, or deliberate disguise |
| Rhythm | phrasing habits | urgency can compress a phrase |
| Focus | meaning-dependent | new contrast or discovery |
| Pitch movement | comfortable range | thought-specific rise, hold, fall |
| Volume | conversation baseline | distance or purpose; never compulsory |
| Texture | easy voiced speech | optional brief breath/laugh; no strain |

Do not associate accents with intelligence. Do not cast villains by nationality.
Do not infer accents from names. A region contains many speech patterns.
Accent strength is not emotion intensity. Fear need not amplify accent features.

## 2. Build the card

Complete one card per recurring speaker. Limit the initial feature set.
Use two accent features initially. Add a third after consistency holds.
This limit is a rehearsal heuristic.

| Field | What to enter |
|---|---|
| Speaker ID | NARRATOR, MINA, READER-1 |
| Source basis | TEXT, CHOICE, UNKNOWN |
| Target | locality; period; language background; scope |
| Goal | preserve voice / learn target / character distinction |
| Reference | exact speaker/page/recording; date |
| Evidence status | see section 3 |
| Accent features | target sound; exact example words |
| Key | UK-P, GA-R, supplied, or defined custom key |
| Delivery features | two features excluding accent |
| Reset phrase | a rehearsal-only phrase |
| Switch trigger | listener/context/word anchor; or none |
| Return | exact speaker/ID boundary |
| Uncertainties | unverified words or variation |

Do not fabricate missing biography. Record only task-relevant information.
For an unspecified invented character, choose. Label the choice as CHOICE.
Do not claim it represents everyone.

## 3. Set the evidence status

| Status | Permitted claim |
|---|---|
| USER-DECLARED | user supplied this target/pronunciation |
| TEXT-CHECKED | page/transcription inspected; identify what it establishes |
| AUDIO-OBSERVED | accessible recording heard; record feature/time |
| PROVISIONAL | teaching approximation or working interpretation |
| UNRESOLVED | insufficient evidence; keep the gap visible |

A playable URL isn't listening evidence. A transcript doesn't establish its accent.
Use dictionary text for lexical variants. Use audio for articulatory imitation.
Never copy archive recordings into packs. Check permission before redistributing assets.
Credit IDEA when its samples inform work.

When feasible, compare two relevant speakers. This checks variation, not authenticity scores.
If evidence is absent, continue meaning-work. Offer provisional practice or request reference.
Never improvise a national caricature. Never pretend a target was verified.

## 4. Use UK-P and GA-R

These are defined teaching targets. Neither represents an entire country.
UK-P preserves the previous pack's key. GA-R supplies a rhotic alternative.
Exact speech has more detail. Respelling cannot capture all phonetic differences.

### UK-P

Use the key in SKILL.md. Postvocalic r is usually absent here.
`car` in isolation uses `kah`. `car engine` may use linking r.
Do not delete every written r. Word-initial r remains: `red`, `rain`.
Do not insert r indiscriminately. Check the phrase and chosen target.

### GA-R

Use these complete symbol definitions:

| Symbol | Reference | Symbol | Reference |
|---|---|---|---|
| ee | see | i | sit |
| e | bed | a | cat |
| ah | father; LOT in this target | aw | thought; target retains contrast |
| uu | foot | oo | moon |
| u | cup | uh | schwa, unstressed |
| ay | day | eye | my |
| oy | boy | oh | go |
| ow | now | air | hair; pronounce r |
| eer | near; pronounce r | ur | nurse; pronounce r |
| ar | car; pronounce r | or | north; pronounce r |
| er | unstressed teacher ending; pronounce r | r | English approximant; no forced roll |
| th | think | dh | this |
| sh | ship | zh | vision |
| ch | chip | j | job |
| ng | sing | g | go |
| y | yes | k/s | use these instead of c |

The target retains LOT/THOUGHT contrast. Many US speakers merge those sets.
For a merged target, define GA-M. Record its vowel rule separately.
Never switch merger rules mid-character.

Hyphens divide syllables. Capitals mark lexical stress.
Bold marks phrase prominence. Capitals do not demand volume.

Don't make every word different. Don't stretch every vowel to signal place.
Practice one contrast within a phrase. Then restore the phrase's meaning.

Keep /t/ when clarity needs it. US tapping is context-dependent and optional.
Never mechanically replace t with d. Check stress, sounds, and target first.
Preserve names, negation, and lexical endings.

| Indian English | [IDEA India 1](https://www.dialectsarchive.com/india-1) | commentary notes p/t/k aspiration | does not define Bengali English |
| Bengali-influenced English | user's chosen reference recording | preserve that speaker's English | region/experience/features until supplied |
| Irish, Welsh, other targets | [IDEA index](https://www.dialectsarchive.com/) | select locality and speaker first | exact target and pronunciation features |

For India 1, aspiration is sample-specific. It is not an India-wide rule.
For France 1, avoid invented substitutions. Do not replace every th with z.
For Scotland, avoid compulsory rolled r. For Australia, avoid compulsory question-like endings.
For Bengali English, reject generic stereotypes. Preserve the user's own voice first.

Turn an available sample into practice:

1. Choose one audible recurring feature.
2. Find two words containing it.
3. Record their phonetic targets.
4. Put them into source phrases.
5. Practice without changing the wording.
6. Check against the reference again.
7. Record uncertainty or drift.

Without listening access, stop acoustic claims. Continue subtext and timing work.

## 6. Preserve voices through situations

| Speaker | Accent baseline | Delivery baseline | Situation | Temporary change | Reset |
|---|---|---|---|---|---|
| NARRATOR | UK-P | thought-led phrasing; conversation pace | reveal | space before named object | next thought |
| MINA | UK-P | directed to one listener; short phrase-launch | reunion | release after "lost" | end S07a |
| PORTER | GA-R | clipped phrase ending; measured entry | reassuring someone | lengthen key instruction | end dialogue |

These are casting choices. They imply no nationality from names.
Two characters may share one accent. Differentiate by attention, intention, and timing.
Never make attributions inherit character accent. First-person narration requires a deliberate choice.

Code-switch only with a reason. Record starting and ending anchors.
Do not make stress trigger it automatically. Do not insert translated speech unrequested.

## 7. Rehearse and check drift

Choose a six-to-ten-word reset phrase. It stays outside the performed source.
Include the chosen accent's anchor sounds. Mark it as rehearsal-only.

Check one exchange, then a return. Compare the character after a scene-change.
Keep listener comprehension as the criterion. Reduce feature density when words disappear.

Track these questions:

- Same accent rules on return?
- Same name pronunciation throughout?
- Emotion mistaken for accent change?
- Narrator restored after quotation?
- Accent features masking source meaning?
- Reference listened to or text-inspected?

No universal authenticity score is claimed.
