## ⚡ Common Tasks

### Run an AI tool (Python)
```bash
cd routines/02_python_toolkit_routine/
python ai_file_organizer_pro.py    # Organize files with AI
python audio2txt.py                # Transcribe audio
python pdf2txtv2.py                # Extract from PDFs
python webscrapper.py              # Scrape websites
```

**First time?** Install dependencies:
```bash
pip install PyQt6 transformers torch pandas requests beautifulsoup4 yt-dlp
```
[See full requirements →](routines/02_python_toolkit_routine/README.md)
