## ⚡ Common Tasks

### Run an AI tool (Python)
```bash
cd routines/02_python_toolkit_routine/
python ai_file_organizer_pro.py    # Organize files with AI
python audio2txt.py                # Transcribe audio
python pdf2txtv2.py                # Extract from PDFs
python webscrapper.py              # Scrape websites
```

**First time?** Install dependencies:
```bash
pip install PyQt6 transformers torch pandas requests beautifulsoup4 yt-dlp
```
[See full requirements →](routines/02_python_toolkit_routine/README.md)

---

### Copy a lesson
1. Open `routines/01_elt365_lessons_routine/`
2. Find the lesson file you want
3. Copy the Markdown text
4. Use in your doc or learning platform

---

### Publish lessons to WordPress
```bash
cd routines/01_elt365_lessons_routine/publisher/
python elt365_lessons_publisher.py
```
Publishes all lessons as drafts to sourovdeb.com

### Read a claims audit
1. Open `routines/03_psychology_claims_audit_routine/`
2. Read the `POST_*.md` file for the short, cited summary
3. Read the matching `AUDIT_NOTES_*.md` file for full sourcing, sample sizes, and funding/COI detail
