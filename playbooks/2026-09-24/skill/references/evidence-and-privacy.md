# Evidence and privacy

## Evidence ledger

Record one row per source:

| Field | Required content |
|---|---|
| ID | Stable local identifier |
| Claim | One testable proposition |
| Origin | User, issuer, counterparty, artifact |
| Date | Event and inspection dates |
| Access | Full, partial, metadata, unavailable |
| Support | What the source establishes |
| Limit | What remains unproved |
| Sensitivity | Public, private, restricted |
| Location | Direct retrievable source |

Use private ledgers for correspondence. Never publish source credentials or tokens. Exclude bank identifiers and family records. Exclude health histories from public examples. Exclude recipient addresses unless required.

## Common evidence traps

A CV reports a claim. It does not award credentials.

Course completion differs from certification. Appeal activity does not change awards. Verify the latest issuer evidence.

A draft proves preparation. A send receipt proves provider acceptance. Neither proves recipient engagement.

A recruitment invitation proves interest. It does not establish employment. A stale vacancy needs rechecking.

An invoice request supports an obligation. It does not prove cash receipt. Attributed sales are not creator income. Gross commission is not net profit.

A repository file proves existence. Documentation may assert untested behavior. A user test proves observed use. Small samples support narrow findings.

Automations establish configured intent. Settings can differ from task titles. Delivery logs establish actual execution.

## Privacy split

First inspect the destination's visibility. Create the shareable method from scratch. Add only task-required public information. Review filenames and hidden metadata too.

Keep correspondence in companion notes. Send those only to verified recipients. Do not include them in commits. Avoid raw exports for convenient evidence.

Never infer publication permission from reading permission. A public playbook can remain useful. Personalization requires no medical disclosures.

## Counterevidence

For each major recommendation, ask:

- What would reverse this choice?
- Does a newer record contradict it?
- Does missing evidence change priority?
- Is an alternative equally plausible?
- Is this preference or prediction?

Do not turn uncertainty into paralysis. Choose reversible tests where possible.
