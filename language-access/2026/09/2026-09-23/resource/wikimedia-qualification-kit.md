# Wikimedia Qualification Kit

## Purpose

Use this kit before applying.

It prevents unsupported eligibility claims.

## Phase A: Identity

- [ ] Create one Wikimedia account.
- [ ] Enable email contact.
- [ ] Record the username.
- [ ] Read conduct rules.
- [ ] Avoid promotional biographies.

## Phase B: Contribution evidence

Make useful contributions first.

- [ ] Correct two instructional pages.
- [ ] Cite edit summaries.
- [ ] Save permanent diff links.
- [ ] Respond to reviewer feedback.
- [ ] Avoid mass edits.
- [ ] Avoid AI-dumped content.

## Phase C: Sandbox pilot

1. Open your user sandbox.
2. Paste the pilot markup.
3. State its draft status.
4. Request Wikibooks feedback.
5. Record every response.
6. Revise before publishing.

## Phase D: Training evidence

Collect existing evidence:

- Lesson plans.
- Workshop slides.
- Attendance records.
- Learner feedback.
- Teaching references.
- Public teaching samples.

Do not invent evidence.

## Phase E: Community involvement

Contact:

- Wikibooks Reading Room.
- Wikimedia France.
- NWE Program Officer.
- One experienced editor.
- One education partner.

Ask these questions:

1. Does this belong here?
2. Which book needs improvement?
3. What experience is missing?
4. Which community should join?
5. Should November be skipped?

## Eligibility gate

| Requirement | Evidence | Status |
|---|---|---|
| Current Wikimedia contributions | Diff links | UNKNOWN |
| Training experience | Existing records | PARTIAL |
| Organising experience | Existing records | UNKNOWN |
| Community involvement | Discussion links | MISSING |
| Future Wikimedia work | Project plan | PROPOSED |
| Open licensing | Licence statement | READY |
| One-to-twelve-month scope | Timeline | PROPOSED |
| USD 500–5,000 budget | Budget | MISSING |
| Conduct compliance | Account history | UNKNOWN |
| Public disclosure accepted | Owner decision | UNKNOWN |

## Go decision

Submit only when every required row becomes READY.

## Stop decision

Postpone when:

- Community involvement remains absent.
- Contributions remain superficial.
- The project mainly benefits GitHub.
- The project mainly benefits WordPress.
- Work resembles paid editing.
- Costs cannot be justified.

## Evidence rules

- Link every contribution.
- Preserve reviewer criticism.
- Separate drafts from publications.
- Record dates and outcomes.
- Report failed attempts.
- Never claim endorsement.
