# Offline Business English Pilot

## Asset

Open `business-english-offline-lesson.html` in any modern browser.

No server is required.

## Purpose

This pilot teaches complaint handling for hospitality work. It supports solo study, pair work, printing, GitHub Pages, and offline packaging.

## Accessibility

- Keyboard controls work.
- Focus indicators remain visible.
- Colour is not required.
- Print output stays readable.
- No audio dependency exists.
- Motion is optional.
- Answers use live regions.

## Testing checklist

1. Disconnect the internet.
2. Open the HTML file.
3. Complete every question.
4. Use only the keyboard.
5. Print the page.
6. Test at 200% zoom.
7. Record learner confusion.
