# Free Business English Without Reliable Internet

Free access means little when access requires constant internet.

That problem changes the design.

A language lesson should open on an old computer. It should survive a weak connection. It should print. It should permit translation. It should explain who may reuse it.

This is the next ELT365 experiment.

## The pilot

I built one short hospitality-English lesson. It teaches four moves for handling a guest complaint:

1. Listen.
2. Clarify.
3. Acknowledge.
4. Offer action.

The lesson uses one HTML file. It needs no external library. A learner can open it offline. A teacher can print it. A translator can adapt it.

The content uses CC BY-SA 4.0. The code uses MIT.

## Why Kolibri

Learning Equality describes Kolibri as an offline-first learning platform. Kolibri Studio lets content creators assemble custom channels. Those channels can contain local documents, audio, video, assessments, and interactive materials. After initial download, content can move offline through local networks, peer-to-peer transfer, or storage devices.

That offers a route beyond my website.

GitHub can keep the source. WordPress can explain the project. Kolibri can carry lessons into places where reliable internet remains unavailable.

Source: [Learning Equality](https://learningequality.org/kolibri/about-kolibri/)

## Why open licensing

UNESCO defines Open Educational Resources as materials in the public domain, or materials released under licences permitting no-cost access, reuse, adaptation, and redistribution.

That matters for language education. Translation is not an afterthought. Local examples are not decoration. They determine whether a lesson works.

UNESCO also identifies accessible formats, multilingual cooperation, and sustainable models as parts of OER development.

Source: [UNESCO OER Recommendation](https://www.unesco.org/en/legal-affairs/recommendation-open-educational-resources-oer)

## What remains unproven

One lesson proves little.

I have not shown learning gains. I have not tested a Kolibri import. I have not completed a French adaptation. I have not built a partner network.

Those are the next tests.

## The seven-day test

- Test the lesson offline.
- Review the language.
- Create one translation.
- Build one Studio channel.
- Import it locally.
- Test with three learners.
- Revise observed problems.

The aim is modest.

Build the course. Build evidence. Keep access free.
