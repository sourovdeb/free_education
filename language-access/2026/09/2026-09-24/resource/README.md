# Translation Sprint Kit

This kit supports ELT365.

It checks translation readiness.

It records license fields.

It exports a JSON record.

## Files

- translation-sprint-board.html
- translation-manifest.csv

## Use

Open the HTML file.

Complete every field.

Choose the source license.

Run the license check.

Save the JSON record.

Ask another reviewer.

Then update the manifest.

## Decisions

ND licenses block sharing.

Unknown rights stop publication.

SA terms must continue.

NC limits commercial use.

Attribution remains mandatory.

Mark all meaningful changes.

## Scope

This tool gives guidance.

It gives no legal advice.

Check the official license.

Seek advice when needed.

## Suggested pilot

Use one ELT365 unit.

Create three language versions.

Use English, French, Bengali.

Test five learners.

Log every correction.
