# Episode 09 sources

## Evidence

- UKVI lists approved tests.
- Routes set different levels.
- Results usually last two years.
- Some candidates must travel.
- Teaching and exams earned £702m.
- That figure covers 2024–25.
- Two studies report earnings gains.
- Free teaching resources exist.

## Inference

- Requirements create steady demand.
- Familiar brands reduce uncertainty.
- Expected returns motivate spending.
- Total costs exceed test fees.

## Unproven

- Price proves teaching quality.
- One score proves competence.
- One actor controls English.
- Every learner needs certification.
