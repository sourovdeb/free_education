# Bangla à la maison

A 14-page early-learning book.

For Bangla-French family reading.

## It contains

- Greeting and name play
- Numbers 1 to 10
- Colours, family, home, and animals
- Two Bengali folk rhymes
- First letters
- Drawing prompts

## Reading key

The pink line supports French readers.

- `ou` = loup
- `é` = été
- `ô` = rose
- `ch` = chat
- `tch` = tchao
- `ã` = nasal sound

The phonetic line supports speech.
It does not replace Bangla spelling.
