# History Investigation — 16:00 edition

This pack investigates contested causation.

It contains six chapters.

- Partition and failed bargaining.
- Berlin’s blockade and airlift.
- Bhopal’s layered safety failures.
- Rwanda’s organized mass violence.
- The NPT’s unequal bargain.
- Costly punishment’s primitive echo.

## Files

- `edition.md` — complete sourced edition.
- `wordpress-draft.html` — unpublished import draft.
- `evidence.svg` — accessible evidence ladder.
- `lesson-viewer.html` — dependency-free viewer.
- `lesson.json` — reusable lesson data.
- `build.py` — document and viewer builder.
- `render_video.py` — offline video renderer.
- `history-investigation.mp4` — silent visual summary.
- `manifest.json` — validation and hashes.

## Offline use

Keep all files together.

Open `lesson-viewer.html` locally.

Use Previous and Next.

Play advances every twelve seconds.

The video remains separately controllable.

## Rebuild

Run `python3 build.py`.

Then run `python3 render_video.py`.

The renderer needs Pillow and FFmpeg.
