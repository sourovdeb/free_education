# Manuscript Lens v0.1

Open-source, evidence-bound editorial assistant for novels, memoirs, and literary prose.

**Author-first:** no automatic ghostwriting or manuscript edits.

## Capabilities
- Analyse narrative structure, voice, dialogue, motifs, and continuity
- Identify cross-chapter connections with passage citations
- Raise decision-changing questions
- Compare alternatives and their narrative costs
- Offer bounded line-polishing proposals, subject to author approval
- Optional local Ollama integration

## Source package
The full source ZIP and standalone agent-skill ZIP were delivered by Gmail to the repository owner's mailbox on 2026-11-12.

The project includes a Python CLI, local browser interface, test suite, documentation, example manuscript, and portable Agent Skill.

## Installation
```powershell
py -m pip install -e .
py -m manuscript_lens serve examples/harbor-bell
```
