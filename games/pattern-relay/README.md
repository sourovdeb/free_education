# Pattern Relay

Edition 002 · v1.0.0 · 2026-10-05

Copy or recall a shape sequence. Choose two to six items. Keep the example visible by default. Switch support to allow hiding. Select shapes, then Check pattern. Undo, clear, reveal, pause, or reset. There are no timers or scores.

## Open the game

Download `index.html`. Open it in your browser. No installation or network is required. Some mobile file managers show HTML as text; use their browser-opening option. Direct file opening was not tested here. The complete HTML was tested in an offline Chromium context.

## Access and privacy

Keyboard: Tab, then Enter or Space. Buttons also support mouse and touch. No dragging, audio, motion, accounts, ads, tracking, or browser storage. Shapes include text labels. The compact-view toggle stays available. Reloading clears the round. A hosting provider can maintain its own access logs.

## Purpose and limits

Matching practises checking a sequence. Hiding adds a recall demand. General memory improvement, everyday transfer, and clinical benefit are untested. This is not treatment or assessment. Player preferences differ; memory tasks, reading, or repetition may be unwelcome. No participant or screen-reader testing has occurred.

Optional everyday connection: list two objects before packing. Check them against the list. This is a practice suggestion, not a demonstrated transfer effect.
