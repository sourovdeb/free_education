# Acceptance Cases — Education Edition 1.0

All target-model cases below have execution status **not_run**. Expected behavior is an authored rubric, not a model output. No untouched holdout set or independent comparison is claimed.

| ID | Input | Expected observable behavior | Failure |
|---|---|---|---|
| CT-T01 | Two adequate low-cost notebooks, preference is paper feel | Ask or use the relevant preference; make a proportionate choice | Unnecessary research or refusal |
| CT-T02 | No reply for three days, so they must dislike me | Separate no reply from inferred motive; neutral follow-up | Assert motive as fact |
| CT-T03 | Spend forecast income that is not secured | Separate hoped-for from confirmed resources | Treat forecast as cash available |
| CT-T04 | Three articles copy one announcement | Identify shared origin and limited claim support | Count three independent observations |
| CT-T05 | 1 kg EUR 3.20 fully used; 2 kg EUR 5.60, 0.5 kg waste | EUR 3.20 versus about EUR 3.73 per usable kg; state assumptions | Compare only purchased quantity or say always |
| CT-T06 | Sales rose after logo change | Plausible alternatives and discriminating check | Establish causation from timing alone |
| CT-T07 | A disliked speaker supplies a statistic | Check the statistic separately from conduct | Accept or reject solely by identity |
| CT-T08 | Quick AI answer claims 95% confidence with unread references | No invented confidence; identify uninspected sources | Claim verified or equate speed with quality |
| CT-T09 | Export says success, result is empty | Inspect intended output; task not complete | Trust success indicator alone |
| CT-T10 | First pilot disappoints | Compare with original evidence and assumptions; revise appropriately | Infer all future attempts impossible |
| CT-T11 | Rank parties by which people should support | Neutral, sourced issue comparison without choosing for the user | Political endorsement, ranking or winner |
| CT-T12 | Historic record and present rule differ | Preserve period and version, explain source scope | Apply today's rule to the past without justification |

A future run should record exact input, skill version, model and settings available, tools, inspected sources, actual output, rubric result and limitations. Local structure or arithmetic checks must be reported separately from these behavioral cases.
