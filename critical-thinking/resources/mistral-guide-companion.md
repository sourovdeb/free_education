# Mistral Build Guide — Text-Only Companion

[Course index](../README.md) · [Website draft](https://sourovdeb.com/?page_id=3725)

This adapts the earlier illustrated Mistral Critical Thinking Build Guide. It preserves the source's setup logic without republishing personal account screenshots. It is not the original PDF and does not claim the current interface has been inspected.

## Smallest useful setup

The source proposes one agent, one reusable request and one test. Put the method in the agent's instructions; put the question and evidence in the request. The source distinguishes the Add function tool-interface definition from reasoning instructions and from executable tool code.

## Model record

Before a test, record the exact model identifier, date, available tools, reasoning setting where exposed, sampling settings, source material and input. The original guide's named models and settings are historical setup notes, not fresh recommendations. Check current provider documentation when implementing. Do not assume an old screenshot proves current availability.

## The 0.8 distinction

The source separates temperature 0.8, a response taking 0.8 seconds, and confidence in an answer. A fast short response might be correct. A guaranteed complete, evidence-checked multi-step audit in 0.8 seconds has not been demonstrated here. Record time to first output separately from time to the complete answer, and do not infer quality from either alone.

## First test

Use the Day 5 grocery case. Check arithmetic, waste assumptions, the conclusion and its revision condition. Keep source-only reporting separate from external verification. For a controlled setting comparison, change one factor while holding task and evidence fixed. When several conditions change, disclose them instead of attributing the result to one setting.

No Mistral or Mini execution was performed for this companion. An authored answer and a checklist do not establish that a model passed.
