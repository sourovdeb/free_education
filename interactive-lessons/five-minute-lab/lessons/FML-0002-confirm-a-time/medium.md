# So, That's 7:30 on Thursday?

**5-Minute English Lab - FML-0002**  
**Level estimate:** A2-B1  
**Goal:** Confirm a booking time.

## Situation

Your shuttle is booked.
It leaves Thursday.
The time is 7:30.

You want confirmation.

```text
HEAR -> FIND DETAIL
     -> REPEAT DETAIL
     -> CHECK
```

## Model

**So, that's 7:30 a.m. on Thursday, right?**

Neutral alternative:

**Is that 7:30 a.m. on Thursday?**

## Try it

Which sentence checks time?

A. Is that 7:30 a.m. on Thursday?  
B. What time is it?  
C. See you sometime Thursday.

**Best answer: A.**

It repeats the detail.
It asks for confirmation.

## Match details

- Thursday -> day
- 7:30 a.m. -> time
- east entrance -> place

## Build the check

`So,` + `that's` + `7:30 a.m.` + `on Thursday,` + `right?`
