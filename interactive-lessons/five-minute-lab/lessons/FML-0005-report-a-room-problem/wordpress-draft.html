The Shower Isn't Working

Goal: Report one room problem. Ask staff to check it.

Situation

You are in a hotel room. The shower does not work. You call reception.

Three-step message

  1. Name the item.
  2. State the problem.
  3. Ask for action.
SHOWER -> ISN'T WORKING -> ASK STAFF TO CHECK

Model: Hi, there's a problem with the shower. It isn't working. Could someone take a look, please?

Choose

Which message names the problem clearly?

  • The shower is bad.
  • There's a problem with the shower. It isn't working.
  • I have a shower.
Answer

The second choice names the item and states what failed.
