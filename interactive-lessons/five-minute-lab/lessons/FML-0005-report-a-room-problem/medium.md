# The Shower Isn't Working

**Goal:** Report one room problem. Ask staff to check it.

## Situation

You are in a hotel room. The shower does not work. You call reception.

```text
NAME ITEM -> STATE PROBLEM -> ASK FOR ACTION
shower       isn't working    take a look?
```

Text equivalent: name the item, state what is wrong, then ask someone to check it.

## Model

Hi, there's a problem with the shower. It isn't working. Could someone take a look, please?

The message does three jobs. It identifies the object. It states the problem. It asks for action.

## Quick check

Which message is clearer?

A. The shower is bad.

B. There's a problem with the shower. It isn't working.

C. I have a shower.

**Answer:** B. It names the item and states what failed.

Now choose the request:

A. Could someone take a look, please?

B. The shower was new.

C. Shower now.

**Answer:** A. It asks someone to examine the problem.

## Try another situation

Your room key does not open the door. Report the problem. Then ask for help.

Possible answer: *My room key isn't working. Could you help me, please?*
