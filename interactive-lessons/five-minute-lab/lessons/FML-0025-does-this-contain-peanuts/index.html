Does This Contain Peanuts?

Goal: State a food allergy, ask whether a dish contains that allergen, and ask staff to check preparation before ordering.

Meet the situation

You have a peanut allergy. You want vegetable curry.

This lesson teaches communication. Staff confirmation still matters.

The model

State: “I have a peanut allergy.”

Ask: “Does this curry contain peanuts?”

Check: “Please check cross-contact before I order.”

Meaning, grammar, tone

Meaning: “Contains” asks about ingredients. “Cross-contact” asks about preparation.

Grammar: Does + singular dish + contain + ingredient?

Tone: Say “allergy,” not “dislike.” Do not treat uncertainty as confirmation.
