## 📖 WHAT IS A PROMPT?

**Simple Definition:**
A prompt is the question or instruction you give to an AI model. It's literally what you type into the chat box.

Think of it like this:
- **Bad prompt:** "Write about AI"
- **Good prompt:** "Write a 500-word beginner's guide to AI. Explain it like you're talking to a 10-year-old. Include 3 real-world examples. Format as a blog post with headers."

**Why do prompts matter?**
Because the quality of your question determines the quality of the answer. A vague prompt gets a vague answer. A detailed prompt gets an excellent answer.

**The Hidden Truth (What Silicon Valley Won't Tell You):**
The model is only as good as the prompt you give it. A Mistral Large with a bad prompt < Mistral Small with a perfect prompt. **Prompt engineering is more important than model size.**

### Step 3: Two Types of Prompts

**1. User Prompt (What You Type)**
- This is your question or instruction
- Go in the "User Message" box
- Examples:
  - "Explain quantum physics"
  - "Write a Python function that..."
  - "What are the benefits of meditation?"

**2. System Prompt (How the Model Behaves)**
- This is optional meta-instruction
- Go in the "System Prompt" box (at the top, hidden by default)
- Examples:
  - "You are a patient teacher. Explain concepts simply."
  - "You are a professional copywriter. Use persuasive language."
  - "You are a debugging expert. Find the bug and explain the fix."

### Step 4: The Difference Between Them

**System Prompt:** Sets the personality/role
- "You are a helpful tutor"
- "You are a sarcastic comedian"
- "You are a Python expert"

**User Prompt:** The actual question
- "Explain recursion"
- "Make a joke about programming"
- "Fix this code: [code]"

**Together:** System + User = Perfect answer

### Mini-Tutorial: Write a Better Prompt

**Goal:** Ask the model for a blog post about learning AI

**Bad Prompt (what NOT to do):**
```
Write about learning AI
```
(Too vague. Model doesn't know length, style, audience, format.)

**Better Prompt (specific and structured):**
```
Write a 1500-word blog post for beginners learning AI.

Requirements:
- Title: "AI for Beginners: A Complete Guide"
- Audience: High school students, zero coding experience
- Tone: Friendly, encouraging, no jargon
- Structure:
  - Introduction (100 words)
  - What is AI? (300 words, with 2 examples)
  - How is AI Used Today? (400 words, with 3 real companies)
  - Getting Started with AI (400 words, with 3 actionable steps)
  - Conclusion (200 words)
- Include a call-to-action at the end
- Format as markdown with headers and bullet points
```

**Result:** The model knows exactly what to produce.

## ❓ WHY SHOULD YOU CARE?

### What Makes a Good Prompt?

**Good prompts have these 5 elements:**

1. **Clear Goal** — What do you want?
   - ❌ "Tell me about cats"
   - ✅ "Write a 200-word guide to cat behavior for pet owners"

2. **Context** — Who is this for?
   - ❌ "Explain machine learning"
   - ✅ "Explain machine learning to a 12-year-old who likes video games"

3. **Format** — How should it look?
   - ❌ "Write a summary"
   - ✅ "Write a bullet-point summary with 5-7 points, each 1-2 sentences"

4. **Tone/Style** — What voice?
   - ❌ "Write a tutorial"
   - ✅ "Write a tutorial in a sarcastic, funny tone that keeps readers entertained"

5. **Length/Detail** — How much?
   - ❌ "Write about productivity"
   - ✅ "Write a 500-word article about productivity tips for remote workers"

### Real Examples: Prompt Quality vs. Answer Quality

**Example 1: Simple Question**

❌ **Bad Prompt:**
"What is learning for gist?"

✅ **Good Prompt:**
"Explain 'listening for gist' as an English teaching concept. What is it? Why do teachers use it? Give 2 practical classroom examples. Keep it under 300 words and suitable for ESL teachers."

---

**Example 2: Creative Writing**

❌ **Bad Prompt:**
"Write a story"

✅ **Good Prompt:**

## 📝 USER NOTES (Key Takeaways)

### Remember These Five Things:

1. **Prompt ≠ Magic Wand**
   - A prompt is instructions
   - Good instructions = good output
   - Vague instructions = vague output
   - The model can only work with what you give it

2. **System Prompt Sets the Role**
   - Tells the model how to behave
   - Example: "You are a patient teacher"
   - Different system prompts = different personality

3. **User Prompt Is Your Question**
   - Be as specific as possible
   - Include: goal, audience, format, tone, length
   - Examples are powerful (show what you want)

4. **More Detail = Better Answers**
   - 2-line prompt = mediocre answer
   - 10-line prompt with structure = excellent answer
   - Spend time on the prompt, save time on editing

5. **Prompt Engineering > Model Size**
   - Small model + perfect prompt > Large model + vague prompt
   - This is why prompt skill matters more than choosing a bigger model

### Common Mistakes to Avoid

❌ **Mistake 1:** Being too vague
- Result: Generic, unhelpful answer
- Fix: Add details. Be specific. Show examples.

❌ **Mistake 2:** Not explaining the audience
- Result: Wrong tone, wrong level
- Fix: Always say "Write this for [audience]"

❌ **Mistake 3:** Asking for too much in one prompt
- Result: Answer gets cut off or oversimplified
- Fix: Break it into multiple prompts or ask for ONE specific thing

❌ **Mistake 4:** Not using the System Prompt
- Result: Model acts generic
- Fix: Use System Prompt to set personality/expertise level

❌ **Mistake 5:** Not giving examples
- Result: Model has to guess what you want
- Fix: Show an example of what good output looks like

### Pro Tips

✅ **Tip 1:** Use the "Format" keyword
- "Format this as: bullet points / a table / JSON / markdown"
- Models love explicit format requests

✅ **Tip 2:** Say "Step by step"
- "Explain this step by step"
- Forces model to break down complex ideas

✅ **Tip 3:** Use "Context" keyword
- "Context: I'm a beginner with no coding experience"
- Helps model calibrate its explanation level

✅ **Tip 4:** Ask for examples
- "Give 3 examples of..."
- Makes abstract concepts concrete

✅ **Tip 5:** Use temperature instruction
- "Be creative" (higher temperature) vs. "Be factual" (lower temperature)
- Controls how much the model takes risks

## The Quick Answer

A **prompt** is simply what you type into an AI chat box. But how you write it determines everything about the answer.

A vague prompt gets a vague answer. A detailed, structured prompt gets an excellent answer.

**This is more important than the model you choose.** A Mistral Small with a perfect prompt beats a Mistral Large with a bad prompt.

## The Truth About Prompts (What Silicon Valley Won't Say)

Prompt engineering matters more than model choice.

Examples:
- "You are a patient teacher"
- "You are a Python expert"
- "You are a sarcastic comedian"

You set this once (usually hidden in the UI).

### User Prompt (What You Type)
This is your actual question or task.

Examples:
- "Explain recursion"
- "Write a haiku about coffee"
- "Fix this bug: [code]"

This is what you type in the chat box.
