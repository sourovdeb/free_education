## 📖 WHAT IS AN AGENT?

**Simple Definition:**
An AI agent is like a super-smart helper that doesn't just answer questions—it actually **does things for you**.

Think of it this way:
- **A chatbot** is like calling customer service: they answer your question and that's it.
- **An agent** is like hiring an assistant: they understand what you need, remember previous conversations, and can access tools (email, calendar, web search) to complete tasks without asking you again.

**Why do agents matter?**
Because they can do **real work**. Not just talk about it—actually do it. This is the future of AI automation.

## 📍 WHERE IN MISTRAL CONSOLE?

**Step-by-Step Navigation:**

### Step 1: Go to Mistral Console
- Open https://console.mistral.ai
- Log in with your Mistral account
- Click on **"Agents"** in the left sidebar

### Step 2: Create a New Agent
- Click the **"+ Create Agent"** button (top right)
- A form appears with key sections

### Step 3: The Three Key Sections

1. **System Prompt** = Agent's Brain
   - This is where you tell the agent how to behave
   - Example: "You are a friendly email assistant. Always be professional."

2. **Tools** = What It Can Do
   - Email Send, Web Search, Files, Calculator
   - Only enable tools your agent will actually use

3. **Memory** = What It Remembers
   - Conversation memory helps the agent recall context
   - Set to 50+ messages for natural conversations

## ⚙️ HOW DOES IT WORK?

**The Mechanism Behind the Scenes:**

```
YOU:    "Send my team an email about the 3pm meeting reschedule"
         ↓
AGENT RECEIVES:
    1. Your message (text)
    2. Context (what was said before - memory)
    3. Available tools (email, web search, files, etc.)
         ↓
AGENT THINKS:
    "The user wants me to send an email.
     Do I have the email tool? Yes.
     What should I put in the email?"
         ↓
AGENT ACTS:
    Calls the "Email Send" tool with:
    - To: team@company.com
    - Subject: "3pm Meeting Reschedule"
    - Body: (generates professional email)
         ↓
TOOL EXECUTES:
    Email is sent ✓
         ↓
AGENT RESPONDS:
    "Done! I've sent the email to your team about the reschedule."
```

**Mini-Tutorial: Create Your First Agent**

1. Go to https://console.mistral.ai → Click "Agents"
2. Click "+ Create Agent"
3. Name: "Email Assistant"
4. Model: Select "Mistral Large"
5. System Prompt: Copy this text:
```
You are a professional email assistant. Your job is to:
1. Write clear, professional emails
2. Check for typos and grammar
3. Send emails when asked

RULES:
- Always be formal but friendly
- Ask for confirmation before sending
- If missing an email address, ask for it
```
6. Tools: Enable "Email Send" + "Files"
7. Memory: Enable "Conversation Memory" (50 messages)
8. Click "Create & Deploy"
9. Test it: "Draft an email to sarah@example.com about the Q3 meeting"

## 📝 USER NOTES (Key Takeaways)

### Remember These Five Things:

1. **Agents ≠ Chatbots**
   - Chatbots answer questions
   - Agents answer questions AND take action
   - Agents need tools to do real work

2. **The System Prompt Is Everything**
   - This is where you program the agent's personality
   - Good prompt = good agent
   - Be specific about rules and behavior

3. **Tools Give Agents Power**
   - Without tools, agents are just chatbots
   - Email, web search, files = real capability
   - Only enable tools your agent needs

4. **Memory Makes It Feel Real**
   - Without memory: agent forgets what you said 5 min ago
   - With memory: feels like a real assistant
   - Always enable conversation memory

5. **Start Simple, Add Complexity**
   - First agent: just one tool (email)
   - Second agent: email + web search
   - Third agent: combine three tools

### Common Mistakes to Avoid

❌ **Mistake 1:** Creating agent without system prompt
- Result: Agent acts random
- Fix: Always write a clear system prompt

❌ **Mistake 2:** Giving agent too many tools
- Result: Agent gets confused
- Fix: Enable only what it needs

❌ **Mistake 3:** Forgetting conversation memory
- Result: Agent feels forgetful
- Fix: Always enable memory

❌ **Mistake 4:** Not testing before important tasks
- Result: Agent makes embarrassing mistakes
- Fix: Always do test run first
