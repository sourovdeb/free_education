## 📖 WHAT IS AN AGENT?

**Simple Definition:**
An AI agent is like a super-smart helper that doesn't just answer questions—it actually **does things for you**. 

Think of it this way:
- **A chatbot** is like calling customer service: they answer your question and that's it.
- **An agent** is like hiring an assistant: they understand what you need, remember previous conversations, and can access tools (email, calendar, web search) to complete tasks without asking you again.

**Why do agents matter?**
Because they can do **real work**. Not just talk about it—actually do it. This is the future of AI automation.

## ⚙️ HOW DOES IT WORK?

### The Mechanism (Behind the Scenes)

**What happens when you give an agent a task:**

```
YOU:    "Send my team an email about the 3pm meeting reschedule"
         ↓
AGENT RECEIVES:
    1. Your message (text)
    2. Context (what was said before - memory)
    3. Available tools (email, web search, files, etc.)
         ↓
AGENT THINKS:
    "The user wants me to send an email.
     Do I have the email tool? Yes.
     What should I put in the email? Let me think about context..."
         ↓
AGENT ACTS:
    Calls the "Email Send" tool with:
    - To: team@company.com
    - Subject: "3pm Meeting Reschedule"
    - Body: (generates professional email)
         ↓
TOOL EXECUTES:
    Email is sent ✓
         ↓
AGENT RESPONDS:
    "Done! I've sent the email to your team about the reschedule."
```

### Mini-Tutorial: Create Your First Agent in Mistral

**Goal:** Build an email assistant that helps you write and send emails.

**Step 1: Go to Agents**
- Visit https://console.mistral.ai
- Click "Agents" → "+ Create Agent"

**Step 2: Name It**
- Agent Name: `Email Assistant`
- Description: `Helps write and send professional emails`

**Step 3: Pick a Model**
- Select: **Mistral Large** (more capable than Small)

**Step 4: Write the System Prompt** (THE MOST IMPORTANT PART)
Copy-paste this into the "System Prompt" field:

```
You are a professional email assistant. Your job is to help users:
1. Write clear, professional emails
2. Check for typos and grammar
3. Send emails to team members

RULES:
- Always be formal but friendly
- Ask for confirmation before sending
- If the user mentions a name without an email, ask "What is their email address?"
- Never use ALL CAPS unless the user says so

Example interaction:
User: "Send Tom a note about the project deadline"
You: "I'll draft that for you. Is Tom's email tom@company.com? 
     Should I mention the deadline is Friday or do you want to specify a date?"
```

**Step 5: Enable Tools**
- Check: ✓ Email Send
- Check: ✓ Files (to read email templates)
- Leave others unchecked (you don't need them yet)

**Step 6: Enable Memory**
- Check: ✓ Enable Conversation Memory
- Set to: 50 messages (so it remembers your last 50 exchanges)

**Step 7: Save & Deploy**
- Click "Create & Deploy"
- Wait ~2 seconds for it to spin up

**Step 8: Test Your Agent**
- Chat box opens on the right side
- Type: `Draft an email to sarah@example.com about the Q3 planning meeting`
- Watch the agent:
  1. Understand your request
  2. Call the email tool
  3. Show you the draft
  4. Ask for confirmation

## 📝 USER NOTES (Key Takeaways)

### Remember These Three Things:

1. **Agent ≠ Chatbot**
   - Chatbot: answers questions
   - Agent: answers questions AND takes action
   - Agents need tools to do real work

2. **The System Prompt Is Everything**
   - This is where you program the agent's personality
   - A good system prompt = a good agent
   - A vague system prompt = vague results
   - Always be specific about rules and behavior

3. **Memory Makes It Feel Real**
   - Without memory: agent forgets what you said 5 minutes ago
   - With memory: agent feels like an actual assistant
   - Turn it on for every agent you care about

### Common Mistakes to Avoid

❌ **Mistake 1:** Creating an agent without a system prompt
- Result: Agent acts random and unpredictable
- Fix: Always write a clear system prompt

❌ **Mistake 2:** Giving an agent tools it doesn't need
- Result: Agent gets confused about what to do
- Fix: Only enable the tools the agent will actually use

❌ **Mistake 3:** Forgetting the agent needs memory
- Result: Agent repeats questions, doesn't feel like it knows you
- Fix: Always enable conversation memory

❌ **Mistake 4:** Not testing before giving it important tasks
- Result: Agent sends that email with the typo
- Fix: Always do a test run first with low-stakes tasks

### Pro Tips

✅ **Tip 1:** Name your agents descriptively
- Good: "Email Draft Assistant for Client Updates"
- Bad: "Agent 1"

✅ **Tip 2:** Use Mistral Large, not Small
- Small is faster (cheaper) but less smart
- Large makes better decisions
- For important agents, Large is worth it

✅ **Tip 3:** Start simple, add complexity
- First agent: just web search
- Second agent: web search + summarize
- Third agent: web search + summarize + email results

✅ **Tip 4:** Keep system prompts short
- Under 500 words is ideal
- Long prompts = agent gets confused
- Clear is better than comprehensive

## The Mechanism (For the Curious)

Here's what's actually happening inside the agent:

1. **Your message arrives** (text)
2. **Agent loads context** (what we've been talking about)
3. **Agent examines available tools** (which functions can it call?)
4. **Agent decides** (which tool should I use? Or should I just talk?)
5. **Agent calls the tool** (sends the API call to email service)
6. **Tool executes** (email actually sends)
7. **Agent reports back** (tells you it's done)

All of this is probabilistic. The agent is guessing (with 95% confidence) what the right next step is. But because it's been trained on billions of examples, it's usually right.

This is why the system prompt matters so much: it gives the agent explicit instructions on *how to guess*. A good prompt = better guesses.
