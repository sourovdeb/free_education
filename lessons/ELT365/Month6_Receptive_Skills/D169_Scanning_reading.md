# ELT365 · D169 — Scanning for specific information in reading

**Idea —** Scanning means moving the eyes rapidly over text to locate one target piece of information, then stopping. It is not careful reading.

**Example —** A traveller scanning a departure board for 'Berlin' does not read every destination. They search only for the target word's visual shape.

**Try —** Give a student any text and a target fact. Challenge them to find it without reading the full text. Count the seconds. That gap is the skill.
