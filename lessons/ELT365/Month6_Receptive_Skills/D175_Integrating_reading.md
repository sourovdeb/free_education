# ELT365 · D175 — Integrating reading with other skills

**Idea —** Reading rarely happens in isolation outside the classroom. Integrating it with speaking, writing, or listening creates richer, more authentic tasks.

**Example —** Students read an article, discuss the argument in pairs (speaking integration), then write a 50-word response (writing integration). One text, three skills.

**Try —** Take your next reading text. Add one speaking task and one writing task that grow naturally from the same text. Note the extra planning time: minimal.
