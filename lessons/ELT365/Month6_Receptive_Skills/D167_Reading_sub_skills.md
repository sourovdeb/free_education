# ELT365 · D167 — Reading sub-skills — the full picture

**Idea —** Reading sub-skills include skimming (gist), scanning (locating), intensive reading (close detail), and critical reading (evaluation). Learners need practice in all four.

**Example —** Reading a news homepage for the lead story is skimming. Finding a postcode in a letter is scanning. Both are daily real-world tasks.

**Try —** Identify one real-world task for each sub-skill. That argument — 'learners will need this outside the classroom' — justifies teaching each explicitly.
