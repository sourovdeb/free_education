## Learning design

Read → locate evidence → write for a reader → evaluate feedback → revise → return to a changed task without AI.

Short entry tasks lead toward sustained reading; they do not replace texts with short videos. The website carries the complete lesson. Print supports access. Captioned video demonstrates decisions. LinkedIn introduces a useful problem and links to the practice.
