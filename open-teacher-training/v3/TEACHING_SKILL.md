# Teaching materials and methods — v3 source edition

This is a self-contained reading copy of the operating procedure. Install the complete `03_skills/teaching-materials-methods/` folder from the master ZIP for the canonical SKILL.md, references, templates, example, manifests and validators. This source edition does not pretend those supporting files are installed.

## Purpose

Produce one usable teacher-training unit or classroom pack. Preserve source meaning. Keep claims traceable. Keep essential learning available without paid AI. Never infer accreditation, tool access, learner consent or publishing permission.

## Activation

Use for lesson design, materials, method selection, reading and writing tasks, scripts, language analysis, answers, rubrics, access adaptations and material review. Do not use for account administration, live publishing, high-stakes grading, certification, surveillance or credential handling.

## Inputs

Recover task mode, primary audience, learner context, outcome, time budget, medium, access constraints and requested artifacts. Read actual supplied sources before relying on titles. Separate teacher trainees from language learners. Record both timings and outcomes. Label assumptions; request missing content when necessary for correctness.

## Output

For a full unit: brief, assumptions, observable outcome, method and alternative, complete input and tasks, learner sheet, teacher guide, answers or criteria, revision, transfer, source notes, access route and review status. Small requests remain small. A draft is not approved or published.

## Procedure

1. Inspect sources, permissions and actual capabilities. Reuse adequate working material and utilities before building replacements. No installation without authority.
2. Define the final learner action and evidence. Watching is not proof of learning. Rehearsal is not observed teaching with real learners.
3. Choose a method for the outcome and context. State one reason and one alternative. Do not force PPP, AI or a single framework into every task.
4. Supply actual materials: source text, script, task input, instructions, grouping, timings, product and feedback. Do not ship “find a text later” as a finished lesson.
5. For reading, model a difficult inference or reference relation; ask for source evidence; add a changed-text return.
6. For writing, specify audience and purpose; inspect a model; plan, draft, receive reader response, revise and explain decisions. Protect the writer’s intention.
7. Use speaking and listening when they serve the outcome. Pronunciation targets intelligibility. A transcript is not evidence of listening performance; audio substitution changes a reading construct. Record accommodations.
8. Connect each answer to the actual task. For open responses, give criteria and acceptable variation. Distinguish uncertainty, contradiction and lack of evidence.
9. Use chunks as entry points, not replacements for complete texts. Reassemble meaning into sustained practice. Do not assume fixed attention limits, talk ratios or word-encounter thresholds.
10. Make AI optional. Ask for an attempt before hints. Verify suggestions against sources. A later independent task excludes answer-generating AI while retaining agreed access support.
11. Separate official requirements, centre guidance, research, project proposals, illustrations and unknowns. A dated handout is not automatically ineffective. No fabricated citations, facts, consent or review.
12. Validate alignment, completeness, language, timing, access, evidence, rights, privacy and release status. Structural code checks do not establish teaching quality.
13. Repair concrete defects. Allow two repair passes, then checkpoint the blocker. Do not loop indefinitely.
14. Return artifacts, executed checks, limitations and one next action. Stop at the authorised scope.

## Glossary distinctions

MFPA covers meaning, form, pronunciation and appropriacy. Some centre sheets use MFPR; register is related to, but not identical with, appropriacy. Concept checks examine meaning; instruction checks examine task understanding. Guided discovery can be a clarification strategy rather than a whole lesson framework. The supplied glossary uses micro-teaching for monitoring support, whereas other contexts use it for a brief rehearsal. State the intended sense.

## Small-model route

Use one stage per turn: brief → outcome → method → material → key → checks. Reload identifiers and source excerpts as needed. Save checkpoints. Escalate a specific unresolved question, not the whole course. No prompt guarantees quality and no size label establishes accuracy.

## Model route

Mistral Small 4 is a documented hosted candidate; Ministral 3 3B is a possible staged local candidate. Verify availability, exact identifier, memory and costs before use. The larger model’s active parameter count does not imply laptop feasibility. No target benchmark occurred in this task.

Compare the same inputs and criteria. Log factual errors, missing inputs, invented citations, repairs, latency and cost. Temperature 0.8 is not 0.8 seconds. Separate first-token latency from complete reviewed output. Use supported defaults before controlled comparisons.

## Stop and recovery

Missing source: identify it, then stop the dependent branch. Contradictory sources: preserve both and explain the conflict. Unavailable tools: return text or a manual route, not fictional execution. Failed upload: retain the artifact and report the exact error. Context limits: checkpoint by unit. Uncertain rights or privacy: keep the candidate private and block public release until resolved.

## Publishing handoff

Publishing is separate. Provide unit ID, version, hash, approval reference, intended action and destination IDs. Keep credentials outside prompts. Verify receipts before retries. Use one execution owner; never activate duplicate schedulers for one lesson.

## Evidence and status

Use SOURCES.md for the evidence base. The master ZIP contains full references and test cases. The skill received static review; Python helpers were tested locally. No Mistral/Hermes target-model behaviour, educator approval or classroom effectiveness was established.
