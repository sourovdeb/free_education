Use START.cmd on Windows.
Choose audit first.
Read the generated report.

Do not install automatically.
Reuse working tools first.

Rendering may need:
- Python;
- Pillow;
- Manim;
- psutil.

TypeSafe is optional.

If TypeSafe is unavailable:
evaluate without networking.
Inspect review.html.
Use manual fallback.

Manual fallback records:
typesafe_verified=false.
