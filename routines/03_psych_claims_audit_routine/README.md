# Routine 3: Psychology / Neuroscience / Marketing / Mental-Health Claims Audit

**What it does:** Picks one widely-repeated claim about human psychology, neuroscience, marketing influence, or mental health treatment, then:

1. Identifies the core claim.
2. Locates the primary research (methodology, sample size).
3. Investigates funding sources (pharma, insurance, university, government) for conflicts of interest.
4. Checks for bias patterns favoring a funder's interests.
5. Compares against independent/opposing research.
6. Publishes a ~200–300 word, source-linked micro-blog news item disclosing funding and conflicts.

**Frequency:** As needed / on schedule
**Output format:** Markdown (.md), one file per audited claim
**Status:** ✅ Active
