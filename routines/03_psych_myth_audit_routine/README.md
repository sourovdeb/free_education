# Routine 3: Psychology / Marketing / Mental Health Myth-Audit

**What it does:** Researches and audits public claims about human
psychology, neuroscience, marketing influence, and mental health treatment —
checking primary sources, sample sizes, funding, and conflicts of interest —
then produces a short, cited micro-blog post (200–300 words) ready to publish
as a WordPress news item.

**Status:** ✅ Active | **Items:** 1 audit post

## Method

1. Identify the core claim.
2. Locate primary sources/research papers; check methodology and sample size.
3. Investigate funding (pharma, insurance, university, government) for
   conflicts of interest.
4. Assess for bias patterns favoring a funder's interests.
5. Compare against neutral/opposing research.
6. Draft a 200–300 word micro-blog post with citations and funding
   disclosure.
7. Deliver the post as a ready-to-publish WordPress news item (see
   publishing note in each post file — this session's WordPress MCP
   connection does not expose post-creation, only site administration, so
   drafts are queued here the same way `routines/01_elt365_lessons_routine/`
   queues lessons for its publisher script).

## Posts

| File | Claim audited | Verdict |
|------|----------------|---------|
| `2026-07-05_chemical-imbalance-theory-of-depression.md` | Depression is caused by a serotonin "chemical imbalance" corrected by SSRIs | Not well supported — independent, non-industry-funded reanalyses (Kirsch 2008, Turner 2008, Moncrieff 2022) find weaker effects than industry-published literature |

## Format

Each post file contains: the claim, a ready-to-publish micro-blog draft, the
step-by-step audit methodology actually followed, a sourcing-confidence note
(minimum two independent sources), and a publishing note.
