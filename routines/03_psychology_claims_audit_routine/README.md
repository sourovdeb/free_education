# Routine 3: Psychology, Neuroscience & Mental-Health Claims Audit

**What it does:** Picks a claim about human psychology, neuroscience, marketing influence, or mental-health treatment; locates primary research; checks funding sources and conflicts of interest; compares against independent/opposing research; and drafts a short, cited micro-blog post auditing the claim.

**Frequency:** As needed
**Output format:** Markdown (.md) — one post + one audit-notes file per claim
**Status:** Active (first item published)

## Process

1. Identify the core claim.
2. Locate primary sources/papers; check methodology and sample size.
3. Investigate funding (pharma, insurers, universities, government) and disclosed conflicts of interest.
4. Assess for bias patterns favoring a funder's interests.
5. Compare against neutral or opposing research.
6. Draft a 200–300 word micro-blog post with citations, funding disclosure, and a verdict.
7. Publish as a draft news item (WordPress publishing is done manually/by a publisher script, matching the review-before-publish pattern used by Routine 1).
