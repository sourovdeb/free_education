# 🧠 Psychology / Neuroscience / Mental-Health Claims Audit Routine

**What it does:** Picks a widely-repeated claim about human psychology, neuroscience, marketing influence, or mental-health treatment; locates primary research; checks funding and conflicts of interest on all sides; compares against opposing/independent research; and drafts a short, cited, funding-disclosed micro-blog post auditing the claim.

**Contains:**
- `posts/` — one file per audited claim, each with the micro-blog post (200–300 words), full source list with DOIs/links, and explicit funding/conflict-of-interest disclosures for every cited study
- Each post also lists what could **not** be verified, rather than filling gaps with guesses

**Frequency:** As needed
**Output format:** Markdown (.md)
**Status:** ✅ Active

## Method

1. Identify the core claim.
2. Locate primary sources; check methodology and sample size.
3. Check who funded the research (pharma, insurers, universities, government) and note conflicts of interest.
4. Look for patterns where conclusions favor a funder's interests — on **all** sides of a debate, not just one.
5. Compare against independent or opposing research.
6. Draft a 200–300 word post with citations, funding disclosures, and a verdict on robustness.
7. Publish as a news item — currently drafted into this repo for review; **not** auto-posted live to sourovdeb.com (see the note in each post) because these topics can involve contested medical claims and named individuals/companies, which warrants a human check before publishing under the site's byline.
