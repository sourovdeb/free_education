# Day 03 — Letter Room

Letter Room makes long-form writing feel like calm correspondence. It gives older readers a large-type starting point while keeping source notes close.

## Included packs

1. wordpress-letter-room: an installable classic theme.
2. github-pages-letter-room: a static GitHub Pages starter.

## Profiles

- Writer: a paper-like writing surface.
- Source Notes: a cool documentation surface.
- Large Type: the spacious default.

## Optional modules

Both packs include a banner maker and three self-paced activities. Every module starts disabled. Sound starts off.

## Safeguards

Readers control pace, hints, sound, motion, contrast, text size, and line spacing. Activities have no timer, flashing, account, tracker, data collection, or treatment claim.

The WordPress pack changes presentation only. It does not change content, URLs, permalinks, media, or live settings.
