# Letter Room user manual

## First install

1. Download letter-room-wordpress-theme.zip.
2. In WordPress, open Appearance, Themes, Add New, Upload Theme.
3. Upload the ZIP, preview it, then activate only when satisfied.

This theme changes presentation only. It does not move posts, change links, edit categories, or alter media.

## What to edit first

Open Appearance, Customize, Letter Room options.

1. Pick Writer, Source Notes, or Large Type. Large Type is the default.
2. Leave tools off unless wanted.
3. Adjust text size and spacing.

## No-code route

Write in WordPress as usual. Use a featured image and meaningful alt text. The theme formats the post list.

## Optional tools

Turn on Banner maker or Optional activities in the same Customizer panel. They remain local to the theme. Activity sound starts off. Pace, hints, contrast, motion, and text size remain user-controlled.

## Annotated example

Use the WordPress editor:

    <p>Dear future reader,</p>
    <h2>Your letter title</h2>
    <p>Explain the idea warmly.</p>
    <h3>Sources and limits</h3>
    <p>Add links and context.</p>

## Safe rollback

Preview first. To return, select your earlier theme under Appearance, Themes. Your writing remains in WordPress.

## Included templates

The theme includes post, page, archive, and optional-activities templates.
