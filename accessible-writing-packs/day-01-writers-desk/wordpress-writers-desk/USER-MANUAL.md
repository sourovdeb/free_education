# Writer's Desk user manual

## First install

1. Download writers-desk-wordpress-theme.zip.
2. In WordPress, open Appearance, Themes, Add New, Upload Theme.
3. Upload the ZIP, preview it, then activate only when satisfied.

This theme does not move posts, change links, or edit categories.

## What to edit first

Open Appearance, Customize, Writer Desk options.

1. Pick Writer, Source Notes, or Large Type.
2. Leave tools off unless wanted.
3. Add a custom logo only if useful.

## No-code route

Write in WordPress as usual. Use a featured image and meaningful alt text. The theme formats the post list.

## Optional tools

Turn on Banner maker or Optional activities in the same Customizer panel. They remain local to the theme.

## Annotated example

Use the WordPress editor:

    <h2>A clear section title</h2>
    <p>Keep one idea per paragraph.</p>

## Safe rollback

Preview first. To return, select your earlier theme under Appearance, Themes. Your writing remains in WordPress.
