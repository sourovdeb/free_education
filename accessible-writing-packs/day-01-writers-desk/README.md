# Day 01 — Writer's Desk

Writer's Desk is the first accessible writing pair.

## Included packs

1. wordpress-writers-desk: a WordPress classic theme.
2. github-pages-writers-desk: a static GitHub Pages starter.

## Profiles

- Writer: paper-like reading surface.
- Source Notes: reference-oriented surface.
- Large Type: larger base text.

## Optional modules

The banner maker and the three self-paced activities ship inside both packs. They start disabled. See each USER-MANUAL.md for activation.

## Scope and safety

The WordPress pack changes presentation only. It never changes existing content, URLs, categories, media, or site settings. The activities are optional practice and make no health or treatment claim.
