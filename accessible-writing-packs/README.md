# Accessible writing packs

This folder holds portable writing packs. Each day adds one WordPress classic theme and one GitHub Pages design pack. Tools are installed but disabled by default.

## Day 01 — Writer's Desk

Goal: a quiet writing surface with selectable Writer, Source Notes, and Large Type profiles.

- WordPress theme source: day-01-writers-desk/wordpress-writers-desk
- WordPress ZIP: day-01-writers-desk/writers-desk-wordpress-theme.zip
- GitHub Pages source: day-01-writers-desk/github-pages-writers-desk
- GitHub Pages ZIP: day-01-writers-desk/writers-desk-github-pages.zip

Both packs include a local banner maker and optional self-paced activities. They have no account, analytics, or medical claim.
