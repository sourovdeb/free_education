# Accessible writing packs

This folder holds portable writing packs. Each day adds one WordPress classic theme and one GitHub Pages design pack. Tools are installed but disabled by default.

## Day 01 — Writer's Desk

Goal: a quiet writing surface with selectable Writer, Source Notes, and Large Type profiles.

- WordPress theme source: day-01-writers-desk/wordpress-writers-desk
- WordPress ZIP: day-01-writers-desk/writers-desk-wordpress-theme.zip
- GitHub Pages source: day-01-writers-desk/github-pages-writers-desk
- GitHub Pages ZIP: day-01-writers-desk/writers-desk-github-pages.zip

Both packs include a local banner maker and optional self-paced activities. They have no account, analytics, or medical claim.

## Day 02 — Source Notebook

Goal: keep claims, evidence, limits, and next actions together.

Presets: Writer, Source Notes, and Large Type.

- WordPress source: day-02-source-notebook/wordpress-source-notebook
- WordPress ZIP: day-02-source-notebook/source-notebook-wordpress-theme.zip
- GitHub Pages source: day-02-source-notebook/github-pages-source-notebook
- GitHub Pages ZIP: day-02-source-notebook/source-notebook-github-pages.zip
- Package commit: https://github.com/sourovdeb/free_education/commit/21cb0292af34eecddd9813462284145f4e5e17ec

Both packs include disabled-by-default banner and activity modules. Readers control pace, hints, sound, motion, contrast, text size, and line spacing.

Presets: Writer, Source Notes, and Large Type.

- WordPress ZIP: day-03-letter-room/letter-room-wordpress-theme.zip
- GitHub Pages source: day-03-letter-room/github-pages-letter-room

- Package commit: https://github.com/sourovdeb/free_education/commit/6ffc9d4d276e12b33588fc0456a7b1bc0c556f0c

Banner and activity modules stay disabled by default. Readers control pace, hints, sound, motion, contrast, text size, and line spacing.
